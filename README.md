# Prova-prática-de-banco-de-dados(NSQL)
Neste repositório será alocado os arquivos correspondente a avaliação, realizada pelo professor: José Neto, ministrador da disciplina Banco de Dados.

 A Prova será dedicada aos assuntos equivalentes a Banco de Dados não relacionais, com o foco em manipulação de scrits em formato arquivo .JSON, os arquivos serão hospedados atráves da interface do pricipal meio para dados NSQL, no caso, MongoDB, podendo ser ultilizado a  sua variação MongoDB Altlas.

 ## Abaixo os comandos exigidos pelo aplicador.

 **1.**  COMANDOS INICIAIS CRUD (CONFIRGURAÇÃO COM O BANCO)
 **2.**  CREATE - EXIGIR QUE O  ALUNO CRIE UM NOVO DOCUMENTO NA COLEÇÃO PARTICIPANTE.
 **3.** READ - EXEIGIR QUE O ALUNO CONSULTE O OBJETO RECÉM INSERIDO.
 **4.** UPDATE - EXIGIR QUE O ALUNO ALTERE UMA LINHA ESPECIFICA EM UM CAMPO.
 ** 5.** DELETE -REMOVE UM CAMPO ESPECIFICO DA COLEÇÃO.
 ** 6** CONSULTA AVANÇADA - SUGERIR QUE O ALUNO USE ALGUM COMANDO DE AGREGAÇÃO.
